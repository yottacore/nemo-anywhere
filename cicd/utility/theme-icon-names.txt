## Every icon name a bundled theme is trimmed down to.
##
## One "<context> <name>" per line. A name ending in -symbolic goes in
## symbolic/<context>, everything else in scalable/<context>. Anything a theme
## doesn't have falls through to Adwaita and then hicolor via Inherits, so a
## gap here costs a mismatched glyph, never a missing one.
##
## The list covers only what the file manager shows. Themes have thousands of
## per-application icons that nemo never asks for, and an explicit list is what
## limits each bundled theme to a few hundred KB.
##
## Read by cicd/utility/vendor-themes.bash.
